# UI v2 Implementation Plan (editable canvas, profile panel, Hebrew/RTL)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the approved UI v2 spec (`docs/superpowers/specs/2026-08-10-ui-v2-design.md`): Select/Draw editing grammar with undo, synchronized side-view profile, and Hebrew-first RTL — vanilla JS, no build step.

**Architecture:** Frontend refactored into ES modules communicating only via `state.js` pub/sub; backend gains additive i18n hooks (explanation language tables, warning codes+params, Hebrew stub keywords, bilingual display names). Orchestration: integrator (main session) does the scaffold (Task 1) and integration (Task 12); Wave 1 runs Agents "backend-i18n" (Tasks 2–5) and "editor" (Tasks 6–8) in parallel worktrees; Wave 2 runs Agents "profile" (Task 9) and "i18n-rtl" (Tasks 10–11) in parallel worktrees.

**Tech Stack:** Python 3.12 / FastAPI / Pydantic v2 (backend), vanilla ES modules + SVG (frontend), pytest, CDP smoke script.

## Global Constraints

- Integer millimeters everywhere; no floats at rest (ADR-0002).
- No new runtime dependencies; no build step; no CDN (fonts bundled locally).
- The plan canvas and profile station axis are NEVER mirrored in RTL; UI chrome is.
- Verbatim user text is immutable and always HTML-escaped (`esc()`) when rendered.
- All existing tests must stay green after every task: `uv run pytest -q`.
- Frontend modules communicate only through `state.js` events + exported functions.
- Every user-visible string in JS goes through `t()`; in HTML through `data-i18n`.
- Commit after every task with a descriptive message.

### Task 7: Select/Draw tools — handles, insert, delete, snapping, typed lengths (editor agent)

**Files:**
- Modify: `src/fenceai/web/static/js/editor.js`, `js/geom.js`, `style.css`

**Interfaces:**
- Consumes: geom helpers, history (Task 6), state events.
- Produces: tool state machine in editor.js; `state.tool ∈ {select,draw,gate,base,ground,pin}`; selection events with `{runId, dotIndex}`. Dots are: run start/end nodes + interior vertices; moving a NODE moves it for all attached runs.
- Key algorithms (implement exactly):
```js
// snapping (draw + drag): given raw mm point p and anchor a (previous dot / other
// end of dragged segment):
//   1. dot snap: nearest existing node within 150mm -> that node
//   2. angle snap: if angle to a within 6deg of k*45deg -> project p onto that ray
//   3. grid snap: round each coord to 100mm
// visual: snapped guide line (class "snap-guide") while active; Alt bypasses 2+3.
// typed length: label click -> <input> in a foreignObject at the label; Enter:
//   direction d = normalize(end - start of the LAST segment of the run);
//   newEnd = start_of_last_segment + d * (typedTotal - lengthUpToLastSegment)
//   (end NODE moves; if the node is shared by other runs, they follow — by design);
//   push snapshot, saveTopology().
// midpoint insert: ghost at segment midpoint; dragstart converts it to a new
//   interior vertex at the drag position (snapped), then normal drag.
// delete: selected interior vertex -> splice from interior_vertices;
//   selected end node of a 2-dot run -> confirm() then delete run (and node if orphaned);
//   events keep their anchors (proportional re-anchor is server-side model behavior).
```
  Draft fixes: Finish/Cancel buttons visible while drafting; Esc cancels; Clear
  clears draft + selection and pushes a snapshot first. Status bar shows
  `t("hint."+tool)` and live cursor `station / x,y` when hovering a run.
- [ ] **Step 1:** Implement Select tool (handles/ghosts/drag/delete + selection events).
- [ ] **Step 2:** Implement Draw tool fixes + snapping + typed-length editing.
- [ ] **Step 3:** Manual browser walk: draw L-shape, drag corner, insert midpoint, delete dot, type exact 6000, undo×5 back to empty, redo×5 forward. `node --check`; commit `feat(web): select/draw editing grammar with snapping and typed lengths`.
